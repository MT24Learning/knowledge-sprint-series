The Complexity Lens

From a rule with no dice to a coast with no single length: what simple rules can build, and how far their patterns can be trusted.

Mohammed Tahri · MT24 · ORCID 0009-0000-9113-1687363738

The Complexity LensPhase summary

Abstract

This issue follows simple rules to the patterns they make. Sprint 36 ran a rule with no dice and still lost the forecast: each 10× sharper start bought only 2.54 more time units. Sprint 37 let residents and grains of sand follow local rules, watched city-wide sorting and avalanches appear, then checked 1 000 real quakes. Sprint 38 measured Britain with eight rulers and Moby Dick’s words with a likelihood test. Each sprint put a popular claim to code, and none survived as usually stated.

Highlights

  • 36Each 10× sharper start buys 2.54 time units; ten more digits buy 24.9.
  • 36Real laser, nearest-past forecast: worst error per pulse 10 → 20 → 37 → 72 → 108.
  • 37Asking for half like neighbours, the city ends 0.79 alike (start 0.50).
  • 37Fiji quakes: b = 1.08 for M ≥ 4.5, 1.22 for M ≥ 4.7; the cut sets b.
  • 38Britain: 2 404 km with a 200 km ruler, 6 958 km with a 1.6 km one.

1 Methods

Three scripts, each run before rendering and re-derived by an independent implementation (pure-Python loops, bisection, stack toppling, my own power-law fit). Data: Santa Fe laser set A, the R quakes set (Fiji), Natural Earth 1:10m, Moby Dick (Gutenberg). Python 3.13.16 · numpy 2.5.3 · powerlaw 2.0.0 · pyproj 3.8.0.

2 Common Misreadings, Checked

  1. “Chaos means it can’t be predicted.”

    Checked Short range works; each 10× sharper start adds 2.54 time units.

    Lorenz 1963 · Sprott

  2. “A butterfly’s flap sets off tornadoes.”

    Checked Lorenz left his 1972 question “unanswered”; a flap could as well prevent one.

    Lorenz 1972 · Palmer 2024

  3. “A sorted map means people wanted it sorted.”

    Checked Asking for half, a model city ends 0.79 alike.

    Schelling 1971 · Epstein 1999

  4. “A coast has one true length.”

    Checked Britain grows from 2 404 to 6 958 km as the ruler shrinks.

    Richardson 1961 · Mandelbrot 1967

  5. “A straight log–log line proves a power law.”

    Checked Moby Dick: R² 0.980, yet a lognormal fits the tail as well.

    Clauset, Shalizi & Newman 2009

In This Issue

  1. Sprint 36/90Dynamics and ChaosChaos is a rule, not dice. A tiny error in the start grows until the forecast is lost.
  2. Sprint 37/90Emergence and Self-OrganisationNobody draws the pattern. Simple local rules build a whole that none of the parts asked for.
  3. Sprint 38/90Fractals, Scaling and the Shape of ComplexityA coast has no length until you name the ruler, and a straight line on a log plot is not yet a law.

Now I Can

Measure a forecast horizon, grow a pattern from local rules, estimate b and D, and test a power law against its rivals.

Mistakes Avoided

Reading chaos as randomness, a grown pattern as proof, a length without its ruler, a straight log–log line as a law.

Phase Project

One notebook: Lorenz twins and a laser forecast, a model city and a sandpile, Britain by eight rulers, words by likelihood.
