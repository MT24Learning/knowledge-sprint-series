One result per phase

Every phase leads with one checked result

Each phase summary opens with one result, checked in code or against the sources. Here they are, in order.

  1. 01
    Engineering Foundations

    Git names every object by the hash of its content: SHA-1 by default, SHA-256 opt-in.

  2. 02
    Foundations of Knowledge

    A positive test with a 1% prior, 90% sensitivity and 5% false alarms is right only 15.4% of the time.

  3. 03
    Calibrating Judgement

    Brier score on 10,000 simulated events: always saying 50% scores 0.250, honest forecasts 0.188.

  4. 04
    Mathematical & Logical Foundations

    0.1 + 0.2 == 0.3 is False in floating point: comparisons need a tolerance.

  5. 05
    Statistics & Experimental Design

    An effect of d = 0.5 needs 64 people per group for 80% power at α = 0.05.

  6. 06
    How Paradigms Die

    The small-angle pendulum formula stays within 1% up to 22° and is 18% off at 90°.

  7. 07
    Data Skepticism & Evaluation Data

    With copied items in the data, a random split scores 1.000 and a split by group 0.440, close to chance.

  8. 08
    Tokenization & Parsing

    2 + 3 * 4: one string, two trees; the grammar picks 14.

  9. 09
    Classical Machine Learning

    “Is it a 9?” Always answering no scores 0.900 accuracy but 0.500 balanced accuracy.

  10. 10
    Neural Networks

    XOR on a bare 2-2-1 sigmoid network: 77 of 100 random starts solve it; with four hidden units, all 100.

  11. 11
    Transformers & Vector Spaces

    king − man + woman returns king itself (0.885); queen (0.852) appears only when the input words are skipped.

  12. 12
    The Complexity Lens

    In a simulation of the Lorenz system, each 10× sharper start buys 2.54 more time units of forecast on average over 24 starts.

  13. 13
    Semantic Search & Retrieval

    On the Cranfield collection, counting words alone scores nDCG@10 0.026; BM25 scores 0.382.

  14. 14
    AI Security & Robustness

    On 540 handwritten digits, random noise of ±2 grey levels leaves a small network at 95.4%; a chosen 10-step attack of the same size leaves 21.5%.

How a sprint works

One idea, one page, five parts

Every sprint image follows the same idea, even as the visual style changes from phase to phase. Each phase then ends with a one-page summary: what each sprint taught, what I can now do, mistakes avoided, and one phase project that ties the sprints together.

  1. 01

    Core concepts

    The idea of the sprint in short cards, written so each one can be checked against its sources.

  2. 02

    A figure

    The main idea drawn, with real numbers where there are any (from Phase 2 onward).

  3. 03

    Try it

    Commands or a short program you can run yourself, shown with its real output.

  4. 04

    A mini project

    One small piece of work to apply the sprint on your own.

  5. 05

    Trusted sources

    Books, papers and official documentation, so every claim can be checked against its origin.
