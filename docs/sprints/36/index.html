Dynamics and Chaos

Chaos is a rule, not dice. A tiny error in the start grows until the forecast is lost.

In short. Deterministic rules, sensitivity to the start, period doubling and Feigenbaum's constant, and what the butterfly really asked.

Survey notes

  1. 1Twins One rule, two starts 10⁻⁸ apart. The runs match until t 20.0, then differ by more than 1.
  2. 2Horizon Each 10× sharper start adds 2.54 time units; ten more digits add 24.9. Mean of 24 starts.
  3. 3Laser Measured data: the closest past stretch tracks the next pulses; the worst error per pulse goes 10 → 20 → 37 → 72 → 108.
  4. 4Route Cycles 2 → 4 → 8 ... crowd in before r 3.57; the gap ratio tends to 4.669.

01 A Rule, Not Dice Determinism

  • Lorenz (1963): three equations, no dice; σ 10 · r 28 · b 8/3
  • Same start, same end: two runs agree to the last bit at t = 50
  • Poincaré (1908): “small differences in the initial conditions produce very great ones in the final phenomena”

Chaos: a fixed rule, no repeats, a sensitive start.

02 Sensitivity Horizon

  • A small error grows like eλt; for Lorenz, λ = 0.906 (Sprott)
  • Mean of 24 starts: twins differ by 1 at t 4.4 from a 10⁻² error, at t 29.3 from 10⁻¹²
  • So each 10× sharper start buys ln 10 ÷ λ = 2.54 time units

A start 10¹⁰ times sharper lasted only 29.3 ÷ 4.4 = 6.7 times longer.

03 Period Doubling Route

  • May (1976): x → rx(1 − x) doubles its cycle 1 → 2 → 4 → 8 ..., then turns chaotic near r 3.57
  • The ratio of successive gaps tends to δ = 4.669 (Feigenbaum 1978)
  • The sine map (r/4) sin πx gives 4.669 too

Universality: the number belongs to the route, not to one model.

04 The Butterfly Misreading

  • Lorenz’s 1972 title is a question, and he left it “unanswered”
  • A flap that can set off a tornado “can equally well” prevent one, he added
  • Palmer (2024): the real butterfly effect (Lorenz 1969b) is a limit smaller errors cannot extend in many-scale flows

In the 1963 model, sharper starts still buy time (card 02).

05 Try It Yourself PYTHON 3.13.16 · NUMPY 2.5.3

sprint36_dynamics_and_chaos.py

import numpy as np
def f(s, sg=10., r=28., b=8/3):  # Lorenz (1963)
    x, y, z = s[..., 0], s[..., 1], s[..., 2]
    return np.stack([sg*(y-x), x*(r-z)-y, x*y-b*z], -1)
def step(s, h=.002):  # one Runge-Kutta 4 step
    k1 = f(s); k2 = f(s + h/2*k1); k3 = f(s + h/2*k2)
    return s + h/6*(k1 + 2*k2 + 2*k3 + f(s + h*k3))
def run(s, t):
    for _ in range(round(t / .002)): s = step(s)
    return s
a, b = run(np.ones(3), 50), run(np.ones(3), 50)
print("same start, same end:", np.array_equal(a, b))
base = run(np.ones((24, 3)) + np.arange(24)[:, None], 30)
d0 = 10.0 ** -np.arange(2, 13, 2)  # first errors
s = np.repeat(base, 7, 0)
s[:, 0] += np.tile(np.r_[0, d0], 24)  # nudge x only
T, t = np.full(len(s), np.nan), 0.0
while np.isnan(T).any() and t < 60:
    s, t = step(s), t + .002
    e = np.linalg.norm(s - s[::7].repeat(7, 0), axis=1)
    T[np.isnan(T) & (e > 1)] = t  # forecast lost
H = T.reshape(24, 7)[:, 1:].mean(0)  # mean of 24 starts
print("lost at t =", " ".join(f"{h:.1f}" for h in H))
k = np.polyfit(np.log10(d0), H, 1)[0]
print(f"each 10x sharper start buys {-k:.2f} time units")
x = np.loadtxt("laser_a.txt")  # Santa Fe set A, real
nxt = np.loadtxt("laser_a_next.txt")  # the hidden 100
W = np.lib.stride_tricks.sliding_window_view(x, 6)[:-100]
j = np.linalg.norm(W - x[-6:], axis=1).argmin()
err = abs(x[j+6:j+46] - nxt[:40])  # follow the analogue
print("laser analogue, worst error per pulse:",
      *err.reshape(5, 8).max(1).astype(int))
def g(r, n):  # 2^n-fold logistic map at x = 1/2, - 1/2
    x = .5
    for _ in range(2**n): x = r*x*(1 - x)
    return x - .5
R = [2.0, 1 + 5**.5]  # superstable r, cycles 1 and 2
for n in range(2, 9):  # Newton's method for cycle 2^n
    r = R[-1] + (R[-1] - R[-2]) / 4.7  # first guess
    for _ in range(40):
        r -= g(r, n) * 1e-9 / (g(r + 1e-9, n) - g(r, n))
    R.append(r)
D = [(R[i]-R[i-1]) / (R[i+1]-R[i]) for i in range(1, 8)]
print("delta:", " ".join(f"{d:.3f}" for d in D))

06 General Notes Practice

  • Forecasters run ensembles: ECMWF runs 50 perturbed forecasts plus a control
  • A widening spread says when to stop trusting the forecast
  • Real laser: the worst error about doubles over four pulses (10 → 20 → 37 → 72), then 108

“Chaos can’t be predicted”: false short range, true past a horizon.
