Supervised Learning: From Examples to a Rule

Remembering every example is easy. Learning is answering the one I have not seen.

In short. Training pairs and a rule, choosing the rule with the fewest mistakes, seen against unseen data, and why no rule works without assumptions.

Determination notes

  1. 1Clash Two flowers at 4.8 × 1.8 cm: one versicolor, one virginica. A rule on petals alone must miss one.
  2. 2ERM Of 42 candidate cuts, width > 1.6 makes the fewest training errors: 3 of 70 (tied with > 1.7).
  3. 3Silent The lookup answers only flowers it saw: 24 of 30 get nothing. Its one wrong answer is the clash.
  4. 4Tie Neighbour and cut both miss 3 of 30. Training errors had ranked them 1 against 3.

01 Pairs In, Rule Out Setup

  • Training data: pairs of measurements x and right answers y
  • The learner returns a rule h for a new x
  • Predict a class: classification. Predict a number: regression

Fisher (1936) analysed iris data collected by Anderson (1935): 50 flowers per species, four measurements in cm.

02 Fewest Mistakes Wins ERM

  • Loss: 0 if the answer is right, 1 if wrong
  • Empirical risk: mean loss on my examples; true risk: on new cases (Vapnik 1991)
  • ERM keeps the rule in my class with the lowest empirical risk

The true risk is never observed. Flowers held out before learning estimate it.

03 Seen vs. Unseen Overfit

  • The lookup misses 1 training flower yet answers only 6 of 30 new ones
  • A memoriser can err 0 on its examples and 1/2 on new ones (Shalev-Shwartz & Ben-David)
  • Test error, not training error, grades learning

Fewer training errors did not buy fewer test errors: 1 and 3 in training, 3 and 3 on test.

04 No Free Lunch Induction

  • Each rule in Fig. 1 carries an assumption
  • With no assumption a learner can only memorise (Mitchell 1997, ch. 2)
  • Over all targets, any two learners win equally often off the training set (Wolpert 1996)

Choosing the class of rules is the assumption. I write it down (Sprint 11).

05 Try It Yourself PYTHON 3.13.15

sprint26_supervised_learning_from_examples_to_a_rule.py

import numpy as np
from sklearn.datasets import load_iris
X, y = load_iris(return_X_y=True)
X, y = X[y > 0][:, 2:], y[y > 0] - 1
# petal length, width in cm; 1 = virginica
i = np.random.default_rng(26).permutation(100)
tr, te = i[:70], i[70:]      # learn / hold out

def err(rule, idx):          # 0-1 loss, summed
    return sum(rule(X[j]) != y[j] for j in idx)
memo = {tuple(X[j]): y[j] for j in tr}
look = lambda x: memo.get(tuple(x))   # or None
near = lambda x: y[tr][np.argmin(
    ((X[tr] - x) ** 2).sum(1))]
cuts = [(f, c) for f in (0, 1)
        for c in np.unique(X[tr, f])]
f, c = min(cuts, key=lambda k: err(  # ERM
    lambda x: x[k[0]] > k[1], tr))
cut = lambda x: int(x[f] > c)
silent = sum(look(X[j]) is None for j in te)
print(len(cuts), "cuts; best:",
      ["length", "width"][f], ">", c)
print("look", err(look, tr), silent,
      err(look, te) - silent)
print("near", err(near, tr), err(near, te))
print("cut ", err(cut, tr), err(cut, te))
