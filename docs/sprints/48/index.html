Building a Verified Reference Set

A test set is a measuring standard. Check its labels, state its errors, name its version.

In short. A test set as a reference standard: flag suspect labels with a model, confirm with people, fix, drop or mark each error, and name every version by a digest.

Verification notes

  1. 1Chain Like a certified material: values, how sure they are, and how they were made.
  2. 2Count Recounted from the released votes, all nine single-label sets match the paper exactly; AudioSet as published. Mean 3.33%.
  3. 3Flags A model flagged 5 440 ImageNet images; people confirmed 2 916 as errors.
  4. 4Name Three honest corrections of one set give three digests. A score must name its version.

01 A Reference Set Definition

  • Items, labels, the rules behind them, and a version
  • A certified material states values with “uncertainties and traceabilities” (VIM 5.14)
  • For labels: agreement, known errors, each item’s source

Aroyo & Welty’s seventh myth: “Once Done, Forever Valid”.

02 Clean Test Sets Claim fails

  • Claim: “a published test set’s labels are correct”
  • Ten sets (two from samples): mean 3.33% errors; ImageNet 2 916 of 50 000 (5.83%)
  • An error: fewer than 3 of 5 people agree with the given label

The paper’s abstract rounds ImageNet up to “at least 6%”; its table says 5.83.

03 Flag, Then Confirm Method

  • A model flags suspects: confident learning (Northcutt, Jiang & Chuang 2021)
  • People check them: 2 524 of 5 440 ImageNet flags (46.4%) kept their label
  • So never relabel on a model’s word alone

AudioSet is multi-label; one rule we inferred gives its 275 exactly, but the paper does not state it.

04 Fix, Drop or Mark Evidence

  • ImageNet errors: 1 428 relabelled · 597 both labels · 293 neither · 598 split
  • IMDB: 552 of 725 errors get no sentiment majority (200 voted neutral)
  • A split is disagreement, not a known right answer (Sprint 46)

Northcutt et al. left multi-label items out of their own analysis.

05 Try It Yourself PY 3.13.18 · STANDARD LIBRARY

sprint48_building_a_verified_reference_set.py

import hashlib, json

SIZE = {"mnist": 10000, "cifar10": 10000, "cifar100": 10000,
        "caltech256": 29780, "imagenet": 50000, "quickdraw": 50426266,
        "20news": 7532, "imdb": 25000, "amazon": 9996437}  # test sets
FLAGGED = {"quickdraw": 6825383, "amazon": 533249}  # only a sample
def load(name):                                     # was checked
    with open(f"{name}_mturk.json", encoding="utf-8") as f:
        return json.load(f)
def given(e):         # votes for the given label (Amazon: by name)
    m, g = e["mturk"], e["given_original_label"]
    return m[g.lower()] if str(g).lower() in m else m["given"]
print(f"{'test set':<10} {'size':>8} checked errors share")
shares = []
for name, size in SIZE.items():
    d = load(name)
    err = sum(given(e) < 3 for e in d)  # under 3 of 5 people agree
    shares.append(100 * err / len(d) * FLAGGED.get(name, len(d)) / size)
    print(f"{name:<10} {size:>8} {len(d):>7} {err:>6} {shares[-1]:5.2f}%")
shares.append(1.35)                 # AudioSet: the paper's own figure
print(f"mean of 10 test sets: {sum(shares) / 10:.2f}%")
kind = {k: [] for k in ("fine", "fix", "both", "neither", "split")}
for e in load("imagenet"):
    m = e["mturk"]
    kind["fine" if m["given"] >= 3 else "fix" if m["guessed"] >= 3
         else "both" if m["both"] >= 3 else "neither"
         if m["neither"] >= 3 else "split"].append(e)
print("imagenet:", " | ".join(f"{k} {len(v)}"
                              for k, v in kind.items()))
def digest(edits, drop=()):       # a release is named by its content
    blob = json.dumps({"edits": sorted(edits), "drop": sorted(drop)})
    return hashlib.sha256(blob.encode()).hexdigest()[:8]
fix3 = [(e["id"], e["our_guessed_label"]) for e in kind["fix"]]
fix5 = [(e["id"], e["our_guessed_label"]) for e in kind["fix"]
        if e["mturk"]["guessed"] == 5]
bad = [e["id"] for k, v in kind.items() if k != "fine" for e in v]
for tag, ed, dr in [("v1.1 relabel 3 of 5", fix3, ()),
                    ("v1.2 relabel 5 of 5", fix5, ()),
                    ("v2.0 drop the errors", (), bad)]:
    print(f"{tag:<21} {50000 - len(dr)} items {len(ed):>4} edits"
          f" sha256 {digest(ed, dr)}")

06 General Notes Practice

  • Name each release by a digest of its content (Sprint 2) and keep the old ones
  • Ship a datasheet (Gebru et al. 2021) or a data statement (Bender & Friedman 2018) with known errors

Bridge: on ImageNet, ResNet-18 overtakes ResNet-50 if mislabelled test items rise by 6% (Northcutt et al. 2021). A ranking depends on the version.
