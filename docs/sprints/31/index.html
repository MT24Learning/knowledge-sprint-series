From Perceptron to Multilayer Network

One neuron draws one straight line. XOR needs a bend, and a hidden layer supplies it.

In short. The artificial neuron and the perceptron, its convergence promise, why XOR defeats a single line, and how a hidden layer bends the space.

  2. 2Hidden Two ReLU units, weights set by hand (Goodfellow et al. 2016), send (0, 1) and (1, 0) to one point.
  3. 3Split In hidden space one line separates: h₁ − 2h₂ gives 0, 1, 1, 0.
  4. 4Train 100 seeds of gradient descent: 2 hidden units solve 77, 4 solve 100. Seed 6 (boxed) freezes at 0.5.

01 One Neuron, One Line Unit

  • Sum weighted inputs, fire past a threshold: an idea from McCulloch & Pitts (1943)
  • Its border is one straight line: w·x + b = 0
  • Rosenblatt (1958) made it learn. Modern rule: after a mistake, add error × input

Rosenblatt’s Mark I machine kept its weights in an array of potentiometers (Smithsonian).

02 A Promise, If… Novikoff

  • If one line separates the classes, the rule stops after a finite number of mistakes (Novikoff 1962)
  • AND: no miss from epoch 6
  • XOR: from epoch 2 every epoch ends on the same weights. A loop, not slow progress

No line separates XOR, so the theorem promises nothing.

03 What XOR Asks XOR

  • Answer 1 when exactly one input is on
  • The best straight line answers 0.5 for all four (Goodfellow et al. 2016, §6.1)
  • Minsky & Papert (1969) proved limits of one-layer perceptrons, not of networks

“The book that killed neural nets” is the official history Olazaran (1996) examined, not a theorem.

04 Bend the Space Hidden

  • Two ReLU units move (0, 1) and (1, 0) onto one point: (1, 0)
  • In that new space one line works: h₁ − 2h₂ gives 0, 1, 1, 0
  • Without a nonlinearity, stacked layers collapse into one linear map

The network does not find a better line. It builds a space where a line is enough.

05 Try It Yourself PYTHON 3.13.15

sprint31_from_perceptron_to_multilayer_network.py

import numpy as np
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
AND, XOR = np.array([0, 0, 0, 1]), np.array([0, 1, 1, 0])
def perceptron(y, epochs=100):      # Rosenblatt's rule
    w, b = np.zeros(2), 0.0
    for e in range(1, epochs + 1):
        miss = 0
        for x, t in zip(X, y):
            err = t - int(w @ x + b > 0)
            w += err * x; b += err; miss += err != 0
        if miss == 0: return f"no miss from epoch {e}"
    return f"{miss} misses in epoch {epochs}"
print("AND", perceptron(AND), "| XOR", perceptron(XOR))
A1 = np.c_[X, np.ones(4)]            # best straight line
print("line", np.linalg.lstsq(A1, XOR)[0].round(3) + 0.)
W, c = np.ones((2, 2), int), np.array([0, -1])
H = np.maximum(0, X @ W + c)         # ReLU (§6.1)
print("hidden", H.tolist(), "out", (H @ [1, -2]).tolist())
sig = lambda z: 1 / (1 + np.exp(-z))
def train(h, seed, steps=5000, lr=0.5):   # 2-h-1 net
    rng = np.random.default_rng(seed)
    W1, b1 = rng.normal(size=(2, h)), np.zeros(h)
    W2, b2 = rng.normal(size=h), 0.0
    for _ in range(steps):
        A = sig(X @ W1 + b1); p = sig(A @ W2 + b2)
        d2 = p - XOR; d1 = np.outer(d2, W2) * A * (1 - A)
        W2 -= lr * A.T @ d2; b2 -= lr * d2.sum()
        W1 -= lr * X.T @ d1; b1 -= lr * d1.sum(0)
    return p
ok = lambda h, s: all(abs(train(h, s) - XOR) < .1)
n = [sum(ok(h, s) for s in range(100)) for h in (2, 4)]
print("2 and 4 hidden units solve", n, "of 100")
bad = next(s for s in range(100) if not ok(2, s))
print("seed", bad, train(2, bad).round(3))

06 General Notes Practice

  • One wide enough hidden layer can approximate any continuous function on a bounded box (Cybenko 1989; Hornik et al. 1989)
  • That proves the weights exist, not that training finds them (Goodfellow et al. §6.4.1)

Count the seeds that succeed. Here 23 of 100 runs froze at 0.5, still there after 200 000 steps.
