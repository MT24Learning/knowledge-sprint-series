Hypothesis Testing, Power & Sample Size

A test too small to find an effect cannot tell me the effect is absent.

In short. The logic of a test, the two kinds of error, what sets statistical power, and how to read a p-value correctly.

01 The Logic of a Test

  • H₀: no effect. H₁: an effect of a stated size
  • p: how surprising data this extreme would be if H₀ were true

Fisher (1925) called p = 0.05, "1 in 20", a convenient limit for judging significance.

02 Two Errors

  • Reject H₀ · H₀ true: Type I · α · H₁ true: Power · 1 − β
  • Keep H₀ · H₀ true: Correct · H₁ true: Type II · β

Neyman & Pearson (1933): fix α first, then pick the test with the most power.

03 What Sets Power

  • Effect size d, sample size n, α and noise
  • n grows like 1/d²: from d = 0.5 to 0.2, 64 becomes 393

Cohen (1992): 26, 64 and 393 per group for d = 0.8, 0.5 and 0.2.

04 Reading p Right

  • p is not the chance that H₀ is true
  • Not significant is not "no effect"
  • Significant is not large or important

ASA statement (2016), principles 2 and 5.

05 Try It Yourself

sprint14_hypothesis_testing_power_sample_size.py

import numpy as np
from scipy.stats import ttest_ind
rng = np.random.default_rng(14)
def run(n, d, k=10_000):
    a = rng.normal(0, 1, (k, n))
    b = rng.normal(d, 1, (k, n))
    p = ttest_ind(b, a, axis=1)[1]
    hit = p < .05
    g = b.mean(1) - a.mean(1)
    return hit.mean(), g[hit].mean()
print(run(64, 0)[0])  # false alarms
for n in (64, 20):
    print(n, *np.round(run(n, .5), 3))

06 General Notes

  • Fix n and α before the data
  • Power for the smallest effect that matters
  • Report the effect and its interval

Low power plus a hit means an inflated effect (Gelman & Carlin, 2014).
