Emergence and Self-Organisation

Nobody draws the pattern. Simple local rules build a whole that none of the parts asked for.

In short. Why more is different, Schelling's model of a sorted city, the self-organised sandpile, and the Gutenberg–Richter law for real earthquakes.

01 More Is Different Emergence

  • Anderson (1972): reducing to simple laws “does not imply the ability to start from those laws and reconstruct the universe”
  • Emergent: a pattern of the whole that no single rule states
  • I find these patterns only by running the rules

Simple parts; the pattern belongs to the whole.

02 Micromotives Schelling

  • Schelling (1971): residents move only when too few neighbours are like them
  • Asking for half, the city ends 0.79 alike; asking for 0.3, it ends 0.65
  • On his small board he found the effect “slight” near a third, “striking” at a half

Claim tested: “a sorted map means people wanted it sorted.” It fails here.

03 Self-Organised Criticality

  • Bak, Tang & Wiesenfeld (1987): a site holding 4 grains gives one to each neighbour
  • Nothing is tuned, yet avalanches run from 1 to 5 902 topplings
  • 57% of grains move nothing; 821 set off 1 000 or more

Sprint 38 asks whether such a spread earns the name “power law”.

04 Real Quakes Data

  • Gutenberg & Richter (1944): log N = a − bM; b ≈ 1 means ten times fewer per magnitude
  • 1 000 Fiji quakes: b = 1.08 ± 0.04 for M ≥ 4.5, the most common magnitude
  • For M ≥ 4.7, the +0.2 Woessner & Wiemer (2005) advise: b = 1.22

Aki (1965), half-bin shift (Utsu 1966); ± = b ÷ √n.

05 Try It Yourself PYTHON 3.13.16 · NUMPY 2.5.3

sprint37_emergence_and_self_organisation.py

import numpy as np
def nb(g, i, j, c):  # like and occupied neighbours
    a = g[max(i-1, 0):i+2, max(j-1, 0):j+2]
    s, o, k = (a == c).sum(), (a > 0).sum(), g[i, j]
    return s - (k == c), o - (k > 0)
def alike(g):  # mean share of like neighbours
    r = [nb(g, *p, g[tuple(p)]) for p in np.argwhere(g)]
    return np.mean([s / o for s, o in r if o])
def city(want, n=40, seed=37):  # Schelling (1971)
    rng = np.random.default_rng(seed)
    g = rng.choice(3, (n, n), p=[.25, .375, .375])
    s0 = alike(g)
    for _ in range(100):
        moved = 0
        for i, j in rng.permutation(np.argwhere(g > 0)):
            c = g[i, j]; s, o = nb(g, i, j, c)
            if o == 0 or s >= want * o: continue
            g[i, j] = 0; E = np.argwhere(g == 0)
            d = ((E - [i, j])**2).sum(1)  # nearest first
            for a, b in E[np.argsort(d, kind="stable")]:
                s, o = nb(g, a, b, c)
                if o == 0 or s >= want * o:
                    g[a, b] = c; moved += 1; break
            else: g[i, j] = c  # nowhere better: stay
        if moved == 0: break
    return s0, alike(g)
s0, s1 = city(1/2)
print(f"start {s0:.2f} alike; wants 1/2, ends {s1:.2f}")
print("ends by demand .1-.7:",
      *(f"{city(w / 10)[1]:.2f}" for w in range(1, 8)))
rng = np.random.default_rng(37)  # BTW (1987) sandpile
z, sizes = rng.integers(0, 4, (50, 50)), []
for k in range(40000):
    i, j = rng.integers(0, 50, 2); z[i, j] += 1; n = 0
    while (z > 3).any():  # topple; edges lose grains
        t = (z > 3).astype(int); n += t.sum(); z -= 4 * t
        z[1:] += t[:-1]; z[:-1] += t[1:]
        z[:, 1:] += t[:, :-1]; z[:, :-1] += t[:, 1:]
    if k >= 10000: sizes.append(n)  # skip warm-up
s = np.array(sizes)
print(f"30000 grains: {(s==0).mean():.0%} topple none,",
      f"largest {s.max()}")
print("sizes 1-9, 10-99, 100-999, 1000+:", *np.histogram(
      s, [1, 10, 100, 1000, 10**6])[0])
q = np.loadtxt("quakes.csv", delimiter=",", skiprows=1)
q = q[:, 4]  # Fiji magnitudes, real (R: quakes)
for mc in (4.5, 4.7):  # Aki (1965), half-bin shift
    m = q[q > mc - .01]
    b = np.log10(np.e) / (m.mean() - (mc - .05))
    print(f"Fiji M >= {mc}: {len(m)} quakes,",
          f"b = {b:.2f} +- {b / len(m)**.5:.2f}")

06 General Notes Practice

  • Epstein (1999): “If you didn’t grow it, you didn’t explain its emergence”; growing it is not proof either
  • A sandpile and a fault share a heavy tail; faults are not sandpiles
  • Mild wishes are enough to sort a model city; that does not show what sorts a real one

Same people, other rule: asking 0.3 ends at 0.65.
