Baselines First

A score means nothing until I know what doing nothing would have scored.

In short. What a baseline is, why accuracy lies on imbalanced data, how the chosen score steers the model, and weak baselines in published work.

  2. 2Rare “No” to all 540 digits scores 0.900 and finds no 9. Balanced accuracy: 0.500.

  4. 4Fix Picked by balanced accuracy, pixel 29 finds 47 of 54 nines. Accuracy drops, balanced rises.

01 What a Floor Is Setup

  • A baseline answers without reading the input: majority class, mean, last value
  • DummyClassifier “makes predictions that ignore the input features” (scikit-learn)
  • A model's claim is its gap above that floor

Holte (1993): on most datasets studied, the best one-attribute rule was as accurate as most learners.

02 Accuracy Lies Imbalance

  • 54 of 540 test digits are 9s: “always no” scores 0.900
  • Balanced accuracy averages the recall of each class: “always no” gets 0.500 (Brodersen et al. 2010)

Recall is the share of a class the rule finds: 0 of 54 nines here. I read all four counts.

03 The Score Steers Loss

  • By accuracy: pixel 38 says “yes” 5 times and finds 1 nine
  • By balanced accuracy: pixel 29 finds 47 of 54 and flags 123 others
  • So the score decides what ERM learns

Logistic regression on all 64 pixels: 0.983 and 0.941. It clears both floors.

04 Weak Baselines Evidence

  • Of 18 neural recommenders, 7 could be reproduced with reasonable effort; 6 of those were often beaten by simple heuristics (Ferrari Dacrema et al. 2019)
  • A method is only as new as the strongest baseline it beat

So I tune the baseline as hard as the model.

05 Try It Yourself PYTHON 3.13.15

sprint27_baselines_first.py

import numpy as np
from sklearn import datasets, dummy, metrics
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split
_, y = datasets.load_iris(return_X_y=True)  # Sprint 26
y = y[y > 0][np.random.default_rng(26).permutation(100)]
tr, te = np.bincount(y[:70])[1:], np.bincount(y[70:])[1:]
print(tr, te, f"{te[tr.argmax()] / 30:.3f}")  # majority

D, d = datasets.load_digits(return_X_y=True)
y9 = (d == 9) * 1                      # is it a 9?
a, b, ya, yb = train_test_split(D, y9, test_size=0.3,
                       stratify=y9, random_state=27)
acc = lambda t, p: (t == p).mean()
bal = metrics.balanced_accuracy_score  # mean recall
no = dummy.DummyClassifier(strategy="most_frequent")
p = {"no": no.fit(a, ya).predict(b)}
for score in (acc, bal):               # 1R-style rule
    fc = [(f, c) for f in range(64) for c in range(17)]
    f, c = max(fc, key=lambda k:
               score(ya, (a[:, k[0]] > k[1]) * 1))
    p[f"px{f}>{c}"] = (b[:, f] > c) * 1
lr = LogisticRegression(max_iter=5000)
p["logistic"] = lr.fit(a, ya).predict(b)
print(len(yb), "test images,", yb.sum(), "nines")
for k, q in p.items():
    print(f"{k:9}{acc(yb, q):.3f}", f"{bal(yb, q):.3f}",
          q.sum())

06 General Notes Practice

  • Fit the baseline on the learn set only
  • Stratify the split to keep the class shares
  • Numbers: R² measures against the mean. Forecasts: MASE divides by the naive forecast's error (Hyndman & Koehler 2006)

In Sprint 26's split the learn-set majority was the test-set minority.
