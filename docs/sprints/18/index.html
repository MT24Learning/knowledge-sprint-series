Documenting How a Model Failed

A failure I write down becomes a boundary. One I forget becomes a trap.

In short. Blameless records, drawing the boundary of a model with model cards and datasheets, Feynman's appendix to the Challenger report, and the file drawer problem.

01 A Blameless Record

  • Impact, actions, root causes, follow-ups
  • Causes, not culprits

Google SRE, ch. 15: set the criteria for writing one before anything fails.

02 Draw the Boundary

  • Say where it still holds, not only where it broke
  • Pendulum: 1% up to 22°, 5% up to 50°

Model cards (2019) and datasheets (2021) state intended use and the conditions tested.

03 Nature Can't Be Fooled

  • Shuttle loss odds: about 1 in 100 (engineers) to 1 in 100 000 (management)

Feynman (1986): “reality must take precedence over public relations, for nature cannot be fooled.”

04 The File Drawer

  • Failures left unwritten bias what others read
  • Rosenthal (1979): journals hold the 5% of chance hits, drawers the 95% of nulls

His extreme case, not a measured share.

05 Try It Yourself

sprint18_documenting_how_a_model_failed.py

import numpy as np
from scipy.special import ellipk
a = np.arange(1, 91)  # release angle, deg
m = np.sin(np.radians(a) / 2)**2
r = 2 / np.pi * ellipk(m)  # exact / model
def edge(tol):  # last angle within tol
  return a[r - 1 <= tol].max()
print("MODEL  T = 2*pi*sqrt(L/g)")
print("HOLDS  <=1% to", edge(0.01), "deg")
print("       <=5% to", edge(0.05), "deg")
print("FAILS  at 90 deg:", r[-1].round(3))
print("CLASS  structure (sin x ~ x)")
