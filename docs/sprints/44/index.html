Prompt Injection: When Data Becomes an Instruction

Roles label the rules and the attack, but the model reads both as one stream of tokens.

01 Prompt Injection Definition

  • Prompt injection (OWASP LLM01): input that changes what the model does in ways the developer did not intend
  • Direct: the user types it. Indirect (Greshake et al. 2023): it waits in a page, a mail or a passage
  • Two goals named by Perez & Ribeiro (2022): hijack the output · leak the hidden prompt

Roles label the parts, but the model enforces no boundary between instructions and data (NCSC 2025).

02 Firm Rules Hold Claim fails

  • Claim: “a firm system prompt stops prompt injection”
  • 1 346 attack–defence pairs from Tensor Trust · in each, the attack fooled at least 2 of 3 models
  • 973 defences (72.3%) had a “never / do not” rule and still fell · 79.2% had text after the attack

Scope: success is the dataset’s record on 2023 models. Defences that held are not in these files.

03 A Phrase Blocklist Filter

  • 6 well-known phrase patterns catch 11.9% of the attacks
  • They flag none of 1 571 benign inputs, but those are 755 distinct short passwords and questions: a weak test
  • Not the characters: 15.2% of non-ASCII attacks caught · 10.5% of the rest

Nasr et al. (2025): adaptive attacks broke 12 recent jailbreak and injection defences, above 90% for most.

04 Indirect Injection RAG

  • The attacker never talks to the model: the instruction rides in on retrieved text
  • Sprint 43’s search, one canary plant per question: rank 1 for 223 of 225 (ranking only)
  • With tools a followed instruction becomes an action (OWASP LLM03 · excessive agency)

Whatever retrieval returns sits next to the rules in the prompt.

05 Try It Yourself PY 3.13.18 · STANDARD LIBRARY ONLY

sprint44_prompt_injection_when_data_becomes_an_instruction.py

import json, re
from statistics import median

def load(name):
    with open(name, encoding="utf-8") as f:
        return [json.loads(line) for line in f if line.strip()]
def pct(xs):
    v = [bool(x) for x in xs]
    return f"{100 * sum(v) / len(v):.1f}%"

hij = load("hijacking_robustness_dataset.jsonl")
ext = load("extraction_robustness_dataset.jsonl")
pairs = hij + ext        # each attack beat its defence on 2+ of 3 models
print(len(hij), "hijacks +", len(ext), "extractions =", len(pairs),
      "pairs")

# 1 · did the defenders write firm rules?
WARN = re.compile(r"\b(do not|don't|never|ignore|must not|refuse|"
                  r"under no circumstances)\b", re.I)
defence = [p["pre_prompt"] + " " + p["post_prompt"] for p in pairs]
print("defences with a 'never / do not' rule:",
      pct(WARN.search(d) for d in defence))
print("defences with text after the attack:",
      pct(p["post_prompt"].strip() for p in pairs))
print("median defence length:", median(len(d.split()) for d in defence),
      "words")

# 2 · would a blocklist of well-known phrases have caught them?
BLOCK = re.compile(r"ignore (all |the |your )?(previous|above|prior|"
                   r"earlier) (instructions|prompt|rules|text)|disregard|"
                   r"forget (all|everything|your)|system prompt|"
                   r"you are now|new instructions", re.I)
with open("cran.qry") as f:              # real questions, not attacks
    qs = re.split(r"\.I \d+\n", f.read().replace("\r\n", "\n"))[1:]
benign = [p["access_code"] for p in pairs] + qs
print("blocklist catches", pct(BLOCK.search(p["attack"]) for p in pairs),
      "of attacks | flags", pct(BLOCK.search(b) for b in benign), "of",
      len(benign), "benign inputs")

# 3 · the goal phrase itself
print("hijacks that type 'access granted':",
      pct("access granted" in p["attack"].lower() for p in hij))
print("attacks using non-ASCII characters:",
      pct(any(ord(c) > 127 for c in p["attack"]) for p in pairs))

06 General Notes Practice

  • NCSC (2025): prompt injection may never be totally mitigated the way SQL injection can be
  • Limit what a fooled model can do: least privilege · confirmation before actions
  • CaMeL (Debenedetti et al. 2025) plans from the trusted query only: 77% of AgentDojo tasks with provable security vs 84% undefended

Bridge: put a canary passage in your own retrieval tests and count how often the answer obeys it.
